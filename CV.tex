以水力测功器为核心对象，完成发动机台架测控系统的方案规划、硬件设计和控制策略设计。
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item \textbf{系统规划：} 梳理发动机台架出厂试验流程，完成测控系统布置框图和硬件整体架构设计。
    \item \textbf{传感器与接口：} 针对转速、扭矩、油门位置、水温、机油压力及进排气参数完成传感器选型与接口电路设计。
    \item \textbf{采集与执行：} 基于微控制器规划多路 A/D、DI 输入和 PWM、DO 输出，并设计人机接口与上位机通信功能。
    \item \textbf{通信与控制：} 比较 RS-232、RS-485 与 CAN 通信方案，设计基于 \textbf{PID} 的定转速或定扭矩控制策略及软件流程。
\end{itemize}

% --- 第三个项目 ---
\textbf{进气道湿壁油膜建模与前馈补偿仿真} \hfill 课程设计 \titlebreak
针对进气道喷射汽油机瞬态空燃比控制问题，建立湿壁油膜模型并验证前馈补偿策略。
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item \textbf{问题建模：} 分析燃油附着、蒸发和动态传输机理，建立湿壁油膜模型，明确其对缸内空燃比偏差的影响。
    \item \textbf{仿真分析：} 基于 \textbf{Simulink} 分析油膜参数 \(X\)、\(\tau\) 对燃油动态传输过程的敏感性。
    \item \textbf{控制优化：} 设计前馈油膜补偿器并在 \(X=0.65\)、\(\tau=0.35\) 条件下验证，分析参数适配、鲁棒性与实时性问题。
\end{itemize}
