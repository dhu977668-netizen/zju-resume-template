\textbf{发动机台架测控系统设计} \hfill 课程设计 \titlebreak
围绕发动机台架试验需求，完成传感器选型、测控硬件规划、通信方案及控制策略设计。
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item \textbf{传感器与接口：} 针对转速、扭矩、油门位置、水温、机油压力及进排气温度/压力等参数，完成传感器选型与接口电路设计。
    \item \textbf{测控系统：} 基于微控制器设计多路 A/D、DI 输入与 PWM、DO 输出方案，并规划人机接口和上位机通信功能。
    \item \textbf{通信与控制：} 比较 RS-232/RS-485 与 CAN 通信方案，设计基于 \textbf{PID} 的定转速或定扭矩控制策略及软件流程。
\end{itemize}

% --- 第三个项目 ---
\textbf{进气道湿壁油膜建模与前馈补偿仿真} \hfill 课程设计 \titlebreak
针对进气道喷射汽油机瞬态工况下的湿壁油膜效应，开展建模、仿真和补偿策略研究。
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item \textbf{机理与建模：} 分析燃油附着、蒸发及动态传输过程，构建进气道湿壁油膜模型。
    \item \textbf{仿真分析：} 基于 \textbf{Simulink} 搭建模型，分析油膜参数 \(X\)、\(\tau\) 对燃油动态传输过程的影响。
    \item \textbf{补偿验证：} 设计前馈油膜补偿器，在 \(X=0.65\)、\(\tau=0.35\) 条件下开展仿真验证，并总结工程应用中的限制与改进方向。
\end{itemize}
